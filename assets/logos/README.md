# Provider marks

These files identify the integrations that ctrl+all supports. Keep their original colors and proportions.

- `claude.svg`: the [official Claude website favicon](https://claude.ai/favicon.svg).
- `copilot.svg`: [GitHub Primer's Copilot icon](https://github.com/primer/octicons/blob/main/icons/copilot-24.svg), blob `201ecf408786f8e248ed4a223262c11c6eb726c0`.
- `opencode.svg`: the [official OpenCode favicon](https://github.com/anomalyco/opencode/blob/dev/packages/app/public/favicon.svg), blob `80804d2579bb75d421335e8c2a062811f9bb02d8`.

The old PNG paths remain available for cached pages. The homepage uses the SVG product marks above.
