What ctrl+all counts.

ctrl+all counts what people do, never what they say. This page lists every event the Mac app can send.

ctrl+all counts what people do, never what they say. The Mac app sends a short list of usage events. The list is below. Each event carries three things: an install id (a random number, not tied to you), the app version, and the experiment names your install was given.

ctrl+all never sends prompts, replies, files, paths, names, emails, or keys. A property holds only a value from the list in this page. Free text is never a property.

How to turn it off

  • Open Settings, then Reports, and turn off "Send usage counts".
  • Or set the environment variable CTRLALL_DISABLE_ANALYTICS=1 for the app engine.
  • Turning it off deletes the install id on your Mac. Turning it on later makes a new id. Rows already stored cannot be traced back to you, so they stay until they expire.
  • Usage counts are on by default for every install.

Where rows live

Rows live in Cloudflare Workers Analytics Engine. Rows expire after 90 days. ctrl+all does not store your IP address.
